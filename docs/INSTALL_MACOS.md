# 安装与使用

[← 返回首页](../README.md) · [排查问题](TROUBLESHOOTING.md) · [构建源码](BUILD_MACOS.md)

## 安装前

Apple Silicon Mac，最低 macOS 13。仓库没有完整成品下载；以下步骤用于你自行持有或本地构建的 ZIP。解压到新目录，不覆盖旧 `.13`。不要只复制单独 `.app`，准备脚本、权限配置和校验清单也要保留。

## 安装步骤

1. 手动退出旧红果，脚本不会替你关闭活动窗口。
2. 在终端进入解压目录，运行 `sh 准备Mac版.command`。
3. 等待文件和架构检查、FFmpeg 签名、Java、后台视频首帧及应用分层签名检查。
4. 自检通过才备份并替换旧安装，成功后打开 `~/Applications/Hongguo.app`。

这是本机 ad-hoc 签名，没有 Apple Developer ID 签名或公证。直接打开 Downloads 中的源应用可能被系统拒绝；请做准备流程，不要关闭全局安全检查。

首次进入需创建游客会话，服务拒绝或网络不可用时会报错，不伪造编号。点击卡片默认先看简介和集数，再主动播放；设置可以改为直接播放。右键卡片追剧，再次右键取消；本地记录不等于云同步。实验登录在设置中，仍有兼容性限制。

## 写入范围

| 路径 | 用途 |
| --- | --- |
| `~/Applications/Hongguo.app` | 应用 |
| `~/Applications/.Hongguo-install.*` | 新副本与自检暂存 |
| `~/Applications/Hongguo-backups/` | 旧应用、版本及校验记录 |
| `~/Library/Application Support/hongguo-desktop/` | 设置、追剧、记录、缓存和诊断 |
| `~/Library/Logs/Hongguo/` | 安装、启动、视频自检日志 |
| 系统临时目录中的独立测试资料 | 隐藏测试，不读取真实登录账号 |

不需要管理员权限，不执行 sudo，不改全局代理、证书、主题、Gatekeeper/SIP、PATH 或启动项。只在新建应用副本内处理下载隔离属性及签名，保留旧账号、钥匙串和备份。暂存与备份可能占用磁盘，确认不用后自行清理，不要删除唯一工作的旧版。

## 验证与恢复

- `验证Mac视频.command`：隐藏静音的合成视频、源桥、解码和首帧检查。
- `验证Mac版.command`：使用独立游客资料做真实服务/播放回归，不发短信。
- `诊断Mac启动.command`：应用打不开也能检查准备与启动阶段。
- 设置 → 导出诊断日志：排查已打开应用中的播放问题。

安装失败先看终端给出的阶段和日志，旧安装不应被替换。需要回退时手动退出新程序，备份新应用与数据，再把已经核实的旧应用恢复到原位置，不混合不同版本的组件。
