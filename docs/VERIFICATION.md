# 验证范围与证据

[← 返回首页](../README.md) · [开发过程](DEVELOPMENT_HISTORY.md)

## 四类结果必须分开

| 类型 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 源码与合成测试 | 状态、参数、权限边界、失败处理符合设计 | 真实服务一定接受请求 |
| 包静态检查 | ARM64、权限/链接/字节/清单正确 | Mac 系统一定允许启动 |
| 共用链路在线回归 | 在测试主机获取真实内容并解码出画面 | 未执行平台的原生窗口/Gatekeeper 行为 |
| Mac 实机检查 | 当前机器安装、组件、自检实际执行 | 所有 Mac、所有服务、真实账号云同步都成功 |

## 已有本地 2.3.4 结果

87 项测试通过，0 失败、0 跳过。隐藏合成自检使用源桥 Range/206、FFmpeg 和 HTML 视频，观察到 14 帧。Windows 主机启用同样的 Mac 媒体路径，真实 1080P 内容解码、进度点击/拖动、保留帧、清晰度、选集、下一集、系列切换、筛选换行和排列偏好均通过。

包中 37 个应用文件与源码一致，552 个 regular 文件校验、14 个符号链接检查通过。557 个基线未修改条目含 282 个原生资源条目，保留 FFmpeg 字节及签名代码页。旧 `.13`、247 个 Windows 成品文件和原 APK 未改变。

`.13` 在 Mac 正常播放由用户确认。2.3.4 本次没有真实 Mac 主机，不把 Windows 结果视为实际 ARM64 执行。安装脚本会在 Mac 本机自检通过后才安装。真实手机号登录和云同步未在本批次验收。

## 公开仓库测试

公开源码不包含原始响应和 HEIC 样本。`npm test` 使用合成数据，87 项中可选图片集成测试缺少本地样本/资源时会跳过；账号测试不是实际登录。

CI 配置面向 Mac runner，只编译公开源码并做离线测试，没有私有运行资源。不能仅凭配置存在就认为 Actions 已执行；也不能把 CI 成功等同真实播放成功。

`npm run test:live` 和 `npm run test:desktop` 需要私有资源并真实请求服务；安装包中的视频自检使用合成视频，在线验证脚本使用新游客。所有桌面测试隐藏、静音，资料独立；不发送短信，不读取已登录账号，不操纵用户活动窗口。

## 开源版与本地成品不同之处

公开界面使用原创 SVG，去掉原 APK 图标；Java 源码只保留运行回调。公开源码新增独立基线组包工具和详细文档，原工作包没有被覆盖。输出整体哈希因此会变化；基线原生二进制仍按字节校验保持一致。

已有开发依赖审计问题见 [SECURITY.md](../SECURITY.md)，不通过强制降级构建工具掩盖问题。测试日志和完整包不在 Git 源码树。维护者已另行发布 .13 和 2.3.4 Release 安装文件；它们与当前公开源码重建包不是同一组字节。现有发布标签保留，不为源码整理强制移动。
